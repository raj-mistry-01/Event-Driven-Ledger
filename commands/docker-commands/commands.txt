STEP 3 — KAFKA DOCKER

Start Kafka:
docker compose up -d kafka

Check Kafka:
docker ps
docker logs kafka --tail 50

Create test topic:
C:\kafka\bin\windows\kafka-topics.bat --create --topic docker-test --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1

List topics:
C:\kafka\bin\windows\kafka-topics.bat --list --bootstrap-server localhost:9092

Start consumer:
C:\kafka\bin\windows\kafka-console-consumer.bat --topic docker-test --from-beginning --bootstrap-server localhost:9092

Start producer:
C:\kafka\bin\windows\kafka-console-producer.bat --topic docker-test --bootstrap-server localhost:9092

Docker services connect to:
kafka:29092

Windows host connects to:
localhost:9092
